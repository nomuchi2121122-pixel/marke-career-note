[ウェブ解析士](aff:web-kaiseki)は、一般社団法人ウェブ解析士協会が認定する、Webマーケティングとデータ活用の知識を測る資格です。費用は**テキストと試験で22,000円、認定講座も受けると33,000円（いずれも税込）**。試験はオンラインで受けられる4択60問です。

「意味ない」という声もありますが、**資格があるだけで評価されるわけではない**という意味で言われることが多く、学んだ内容を実務や転職活動で使える人にとっては、知識を整理する手段として役立ちます。

## ウェブ解析士の概要

協会の公式サイトによると、ウェブ解析士の上には「上級ウェブ解析士」「ウェブ解析士マスター」があり、段階的にステップアップできるしくみです。学ぶ内容は、ウェブ解析の基本指標、KPI設計、事業分析、ユーザー行動分析、広告効果測定、コンテンツ分析、ソーシャルメディア分析、GA4の操作と活用、レポーティングなどです。2025年版からは、生成AIの活用と評価も出題範囲に加わったと案内されています。

### 試験の内容

| 項目 | 内容 |
|---|---|
| 形式 | 4択の選択式 |
| 問題数・時間 | 60問・60分 |
| 受験方法 | オンライン（インターネットにつながるPCを使用） |
| 受験日時 | 申し込んだ試験の受験期間内なら、都合のよいタイミングで受験できる |
| 結果 | 試験終了直後に合否が判定される |
| 出題範囲 | 公式テキストの内容に沿って出題。試験には公式テキストを持ち込める |

協会のカリキュラムは1月〜12月の年度ごとに更新され、テキスト・講座・試験は1月に新しくなります。年内に取りたい場合は、11月までに検討するよう公式サイトで案内されています。

## 費用

| | 認定講座を受けない場合 | 認定講座を受ける場合 |
|---|---|---|
| 公式テキスト | 4,400円 | 4,400円 |
| 認定講座 | ― | 11,000円 |
| 試験（認定費用込み） | 17,600円 | 17,600円 |
| 合計 | **22,000円** | **33,000円** |

（2026年11月時点の公式サイトの表示。税込）

認定講座は任意で、講座を受けずに試験だけ申し込むこともできます。なお、講座に申し込んだだけでは試験は受けられないので、試験は別に申し込む必要があります。また、資格を維持するための条件も定められているため、取得前に公式サイトで確認しておきましょう。

## 学習時間の目安

公式サイトでは、テキストを読み込む時間を目安として、次のように案内されています。

| | 期間の目安 | 学習時間の目安 |
|---|---|---|
| ウェブ業界の経験者 | 1か月〜1か月半 | 15〜30時間 |
| ウェブ業界の未経験者 | 2か月〜4か月 | 40〜60時間 |

週に5時間ほど確保できれば、未経験でも2〜3か月で受験まで進めるイメージです。

## 「意味ない」と言われる理由

「意味ない」「いらない」と言われる理由は、主に次の3つです。

1. **資格がなくてもWebマーケターになれる**：厚生労働省の職業情報サイト（job tag）でも、Webマーケティングの仕事に就くために特に学歴や資格は必要とされないと説明されています
2. **資格だけでは実務の評価につながりにくい**：採用や評価では、実際に数字を見て改善した経験が重視されやすい
3. **合格が目的になりやすい**：試験に受かっても、学んだ指標やKPIの考え方を仕事で使わなければ、変化を感じにくい

逆に言えば、**学んだ内容を仕事や個人の取り組みで使い、その結果を説明できる**なら、資格は「体系的に学んだ証拠」として意味を持ちます。

## ウェブ解析士が役立つ人・優先度が低い人

| 役立ちやすい人 | 優先度が低い人 |
|---|---|
| 広告・SEO・SNSなど一部の領域しか知らず、全体を整理したい人 | すでに解析・改善の実務経験が豊富で、実績で説明できる人 |
| 未経験からWebマーケを目指し、基礎を体系的に学びたい人 | 広告運用など特定の操作スキルだけを早く身につけたい人 |
| 営業・制作・企画など隣の職種で、マーケの数字を理解したい人 | 資格を取ること自体が目的になっている人 |
| 社内やクライアントに、データにもとづいた提案をしたい人 | |

## 転職でどう使うか

未経験からの転職では、資格名を書くだけでなく、**学んだ内容を使って何をしたか**をセットで書くと伝わりやすくなります。

- 例：「ウェブ解析士の学習で学んだKPI設計の考え方を使い、個人ブログの目標と指標を設定。3か月間の数値の変化と改善内容をまとめた」

職務経歴書の書き方は[未経験からWebマーケターへの職務経歴書の記事](/articles/web-marketer-career-change-resume/)で詳しく解説しています。資格よりも実践的な課題やフィードバックを重視したい場合は、[Webマーケティングスクールの選び方](/articles/how-to-choose-webmarketing-school/)も参考にしてください。

## よくある質問

### ウェブ解析士は独学で取れますか？
取れます。認定講座の受講は任意で、公式テキストで学んで試験だけ申し込むこともできます。公式の問題集も市販されています。

### 合格率はどのくらいですか？
公式サイトの試験概要ページには、合格率の記載は見当たりませんでした（2026年11月確認）。他サイトに掲載されている数字は時期によって変わるため、最新の情報は協会に確認してください。

### 上級ウェブ解析士から受けられますか？
受けられません。公式サイトのよくある質問によると、上級ウェブ解析士の申し込みには、ウェブ解析士の資格が必要です。

## まとめ

- 費用はテキスト＋試験で22,000円、講座も受けると33,000円（税込）。試験はオンラインの4択60問・60分
- 資格そのものより、学んだ指標やKPIの考え方を実務や職務経歴書でどう使えるかで価値が決まる
- マーケの知識を体系的に整理したい人、未経験から基礎を固めたい人に向いている

費用や試験の条件は年度ごとに変わることがあるので、申し込み前に[ウェブ解析士協会の公式サイト](aff:web-kaiseki)で最新情報を確認してください。
